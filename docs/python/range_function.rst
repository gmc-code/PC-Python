==================================
Python range() Function
==================================

| In Python, the **``range()``** function is a built-in feature used to generate a sequence of numbers.
| It is most commonly used in **``for`` loops** to control how many times a loop repeats or to iterate through a sequence of numbers.
| Instead of writing out lists of numbers manually, ``range()`` generates numbers efficiently on demand.

.. code-block:: python

    # Simple loop using range() to repeat an action 5 times
    for i in range(5):
        print("Loop count:", i)

    # Output:
    # Loop count: 0
    # Loop count: 1
    # Loop count: 2
    # Loop count: 3
    # Loop count: 4

----

Understanding Arguments (stop, start, step)
===========================================

The ``range()`` function can take up to three arguments to control how the number sequence is generated:

- **Single Argument ``range(stop)``**: Generates numbers starting from ``0`` up to, but **not including**, the ``stop`` number.
- **Two Arguments ``range(start, stop)``**: Generates numbers starting from ``start`` up to, but **not including**, the ``stop`` number.
- **Three Arguments ``range(start, stop, step)``**: Generates numbers from ``start`` up to ``stop``, incrementing by ``step`` each time.
- **Negative Step (Counting Down)**: Using a negative ``step`` value allows you to count backwards from a higher number to a lower number.

.. code-block:: python

    # 1. Single argument: range(stop)
    print(list(range(4)))  # Output: [0, 1, 2, 3]

    # 2. Two arguments: range(start, stop)
    print(list(range(2, 6)))  # Output: [2, 3, 4, 5]

    # 3. Three arguments with positive step: range(start, stop, step)
    print(list(range(1, 10, 2)))  # Output: [1, 3, 5, 7, 9]

    # 4. Three arguments with negative step (Counting Down)
    print(list(range(5, 0, -1)))  # Output: [5, 4, 3, 2, 1]

Practical Applications (len, indexing, list conversion)
======================================================

Combining ``range()`` with other Python functions unlocks powerful loop patterns:

- **Using ``len()`` with ``range()``**: Use ``range(len(sequence))`` to iterate through list indexes by position integer.
- **Converting to List**: Passing ``range()`` into ``list()`` converts the range generator object into an explicit Python list.
- **Memory Efficiency**: ``range()`` generates sequence numbers on the fly rather than creating huge lists in memory at once.
- **Indexing Lists**: Allows reading or modifying elements at specific positions inside a collection.

.. code-block:: python

    fruits = ["apple", "banana", "cherry"]

    # Iterate using index positions
    for i in range(len(fruits)):
        print(f"Index {i}: {fruits[i]}")

    # Output:
    # Index 0: apple
    # Index 1: banana
    # Index 2: cherry

    # Converting range directly to a list object
    num_list = list(range(1, 6))
    print(num_list)  # Output: [1, 2, 3, 4, 5]
