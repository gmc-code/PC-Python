===========================
Iteration (Loops)
===========================

| In programming, **iteration** means repeating a block of code multiple times.
| Instead of writing the same code over and over again, iteration allows computer programs to process repetitive tasks efficiently.
| Python provides two primary types of loops for iteration:
| 1. **For Loops**: Used when you know in advance how many times you want to repeat a block of code (definite iteration).
| 2. **While Loops**: Used when you want to repeat code as long as a condition remains ``True`` (indefinite iteration).

.. code-block:: python

    # Simple repetition using a for loop
    for i in range(3):
        print("Hello, World!")

----

For Loops and the range() Function
==================================

A ``for`` loop iterates over a sequence of numbers generated by the built-in ``range()`` function or items in a collection:

- **range(stop)**: Generates numbers starting from `0` up to (but not including) the `stop` number.
- **range(start, stop)**: Generates numbers starting from `start` up to (but not including) `stop`.
- **range(start, stop, step)**: Generates numbers incrementing by `step` value each step.
- **Loop Variable**: A variable (often named `i`, `count`, or `item`) holds the current value during each iteration.

.. code-block:: python

    # Counting from 0 to 4
    for i in range(5):
        print(i)

    # Counting from 1 to 5 with a custom start
    for count in range(1, 6):
        print(count)

    # Counting by twos (even numbers) using step
    for num in range(2, 11, 2):
        print(num)

While Loops and Condition-Controlled Repetition
==============================================

A ``while`` loop repeats a block of code continuously **as long as** a specified condition evaluates to ``True``:

- **Indefinite Iteration**: Ideal when you do not know beforehand how many iterations will be required (e.g., waiting for user input).
- **Loop Control Variable**: You must update variables inside the loop body so the condition eventually becomes ``False``.
- **Infinite Loops**: If the loop condition never becomes ``False``, the loop runs forever, freezing the program!

.. code-block:: python

    # Counting to 3 with a while loop
    counter = 1

    while counter <= 3:
        print("Count:", counter)
        counter = counter + 1  # Crucial: update loop variable to avoid infinite loop!

    print("Loop finished!")

Loop Control Statements (Break and Continue)
===========================================

Python provides special control statements to alter standard loop behavior:

- **break**: Immediately **terminates** the loop entirely, passing control to the statement directly after the loop.
- **continue**: Skips the remainder of the **current** iteration and jumps directly to the next loop evaluation.

.. code-block:: python

    # Using break to exit early
    for num in range(1, 10):
        if num == 5:
            break  # Exit loop when num hits 5
        print(num)  # Prints 1, 2, 3, 4

    # Using continue to skip an iteration
    for num in range(1, 6):
        if num == 3:
            continue  # Skip printing 3
        print(num)  # Prints 1, 2, 4, 5

Nested Loops
============

Placing one loop inside another loop is known as **nested iteration**:

- **Outer vs. Inner Loop**: For **each single pass** of the outer loop, the inner loop completes **all** of its iterations.
- **Total Iterations**: Total execution count equals (Outer Iterations) $\times$ (Inner Iterations).
- **Grid and Matrix Processing**: Commonly used to process 2D grids, tables, or coordinate patterns.

.. code-block:: python

    # Nested loop to print a coordinate grid
    for row in range(1, 3):        # Outer loop (runs 2 times)
        for col in range(1, 4):    # Inner loop (runs 3 times per outer pass)
            print(f"({row},{col})", end=" ")
        print()  # New line after inner loop completes
